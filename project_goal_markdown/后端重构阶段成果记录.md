### LangGraph Agent 升级

修正时间：2026-05-21

- 新增 `redteam_engine/workflow.py`。
- 新增 `RedTeamGraphAgent` 和 `RedTeamGraphState`。
- 红队执行流程从手写循环升级为 LangGraph `StateGraph`：

```text
START -> execute_round -> update_state -> should_continue -> execute_round | END
```

- `execute_round` 复用 `RedTeamOrchestrator._execute_round`，避免 Trace、防护建议、回归集写入逻辑重复。

- 当前采用 StateGraph agent，不采用 ReAct 工具调用 agent；ReAct 工具调用更适合后续 `agent_security` 工具越权沙箱。
