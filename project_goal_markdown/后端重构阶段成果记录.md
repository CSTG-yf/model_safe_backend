# 后端重构阶段成果记录

## 阶段 3：题库生成与模型评测增强

完成时间：2026-05-20

### 完成内容

1. 题库生成服务重构基础能力
   - 新增 `question_bank/schemas.py`：使用 Pydantic 定义生成题目、选项、风险标签和批量结果结构。
   - 新增 `question_bank/quality.py`：提供字段完整性、答案/风险标签存在性、评分标准完整性等质量校验。
   - 新增 `question_bank/generation_service.py`：通过 `ModelGateway` 调用模型，要求 JSON 输出，解析后校验并写入结构化题库表。

2. 裁判评分服务重构基础能力
   - 新增 `model_evaluation/judge_service.py`。
   - 统一评分输出结构：`score`、`risk_level`、`reason`、`evidence`、`confidence`、`passed`。
   - 支持 `capability`、`safety`、`jailbreak`、`rag`、`agent` 五类 rubric。
   - 对非结构化裁判输出提供兜底解析，避免单次模型格式错误直接中断流程。

3. 评测指标体系扩展
   - 新增 `MetricDefinition` 和 `MetricValue` 模型。
   - 新增 `model_evaluation/metric_registry.py` 默认指标清单。
   - 默认指标覆盖：
     - 越狱成功率
     - 隐私泄露率
     - 有害内容生成率
     - 幻觉率
     - 毒性指标
     - 危险工具调用率
     - RAG 污染命中率
     - 回归通过率
     - 题库字段完整率
     - JSON 解析成功率
