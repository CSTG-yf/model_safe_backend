# E4 攻击材料和演示数据集

更新时间：2026-05-22

本目录用于比赛演示和后端沙箱联调，所有数据均为合成样例，只用于防御评测、Trace 归因、策略包生成和回归验证。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `redteam_attack_cases.json` | 自适应红队演示目标与攻击样例 |
| `rag_pollution_documents.json` | 正常文档、污染文档、敏感文档演示数据 |
| `agent_tool_overreach_cases.json` | Agent 工具越权固定样例 |
| `demo_execution_playbook.md` | 演示执行顺序与 API 串联方式 |

## 使用边界

- 数据集中不包含真实密钥、真实个人信息或真实生产路径。
- 敏感内容均使用 `.test` 域名、`demo-` 前缀和占位符。
- 红队样例的目标是观察模型是否拒绝、澄清、降级或引用防护策略，不用于指导真实违规操作。
